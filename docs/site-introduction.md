# 我做了个还不成熟的社区，想认真做一件事

网站地址：<https://www.atoman.org>

我在做 **Atoman**。它的目标不是再做一个靠算法推内容、靠情绪拉互动的平台，而是尝试打造一个**高质量、尽可能少限制、以求真为核心的纯净社区**。

这里当然可以有不同观点，甚至可以有激烈的争论；但我希望讨论尽量回到事实、证据和逻辑本身。少一点表演、跟风和信息噪声，多一点认真阅读、独立判断和真实交流。

目前站内的模块比较多，它们都围绕“发现、整理、表达与讨论”这件事：

- **订阅**：聚合 RSS、博客、播客等更新，支持分组、搜索、筛选规则、收藏与稍后阅读。把真正关心的信息收在一起，按自己的节奏看。
- **博客与短话**：可以发布长文，也可以随手记录几句；文章可通过频道和合集整理，并支持订阅、阅读与收藏。
- **音乐**：整理艺人、专辑、歌曲和歌单，支持播放、导入、收藏和歌词注释。希望它不只是播放器，也是一份能持续积累的音乐档案。
- **论坛**：发帖、回复与搜索的讨论空间，适合围绕具体问题慢慢聊清楚。
- **辩论**：把有分歧的话题单独拿出来讨论，尽量让不同立场围绕论点和依据交锋，而不是互相贴标签。
- **人物时间线**：用时间与事件梳理人物和话题的来龙去脉，帮助理解背景，而不只看一个孤立的结论。
- **播客与视频**：收录和发布更适合用声音、画面表达的内容，让信息的呈现不局限于文字。
- **Studio 与互动功能**：创作者可以管理频道、内容、发布和互动；站内也有评论、点赞、通知、私信、个人设置等基础能力。

这不是一个已经成熟的网站。很多功能还在完善，体验和内容也需要时间积累，难免会有不顺手或不完整的地方。但方向是明确的：做一个能安静获取信息、认真表达观点、坦诚讨论问题的地方。
