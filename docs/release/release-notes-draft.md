# Release Notes Draft

## 中文

Atoman Frontend 0.1.1 完成多内容空间的统一前端基础，并形成 Feed、Blog、音乐、论坛、播客和视频的主要使用闭环。
- 音乐：支持 Fisher-Yates 算法洗牌，并保证正确性。
- 音乐：实现跨 Tab 播放器同步控制，以及支持设备级 MediaSession 控制。
- 音乐：支持纯前端音频上传提取 ID3 标签。
- 音乐：新增前端 API SWR 缓存机制实现。

## English

Atoman Frontend 0.1.1 establishes a unified foundation for multiple content spaces and completes the main workflows across Feed, Blog, Music, Forum, Podcast, and Video.
- Music: Implemented Fisher-Yates shuffle algorithm for accurate playback queue randomization.
- Music: Added Cross-Tab playback synchronization and MediaSession API support.
- Music: Added support for pure-frontend ID3 tag extraction during audio uploads.
- Music: Implemented a new SWR (Stale-While-Revalidate) caching mechanism for frontend APIs.
