# 全站 UI 问题审查报告

**日期**: 2026-10-09  
**审查范围**: Atoman-Frontend 全部模块，共约 150 个 `.vue` 文件  
**设计规范基准**: Pure-White Double-Notch Minimal System（`style.css`、`design_system.md`、`AGENTS.md`）

---

## 设计规范速查

| 规则 | 要求 |
| :--- | :--- |
| **R1 纯白表面** | 卡片、面板、Sheet、表格背景必须为 `#ffffff` / `var(--a-color-bg)`，禁止 `var(--a-color-surface)` (`#f8fafc`) |
| **R2 柔和分界** | 外层边框 `var(--a-color-border)` (`#cbd5e1`)，内部分割 `var(--a-color-border-soft)` (`#e2e8f0`)，禁止 `rgba(0,0,0,x)` |
| **R3 阴影** | 只允许 `var(--a-shadow-*)` 标记，禁止硬编码 `rgb()` / 像素投影 |
| **R4 圆角** | 卡片和控件统一 `4px` / `var(--a-radius-card)` / `var(--a-radius-control)`，禁止 `8px`、`12px`、`16px`、`999px`、`50%` |
| **R5 字重** | 标题 `font-weight: 500`，强调态 `600`，禁止 `650`、`700`、`800`、`900`、`bold` |
| **R6 主色** | `var(--a-color-primary)` (`#2563eb`)，禁止硬编码蓝色 |
| **R7 表单控件** | `<select>`/`<input>`/`<textarea>` 必须升级为 `PSelect`/`PInput`/`PTextarea` |
| **R8 文案** | 禁止开发者视角词汇（"内部"、"System"、"审核理由"、"UUID"、"R2" 等），动作文案使用用户常用表达 |
| **R9 组件契约** | 使用 `PButton`、`PModal`、`PSheet`、`PConfirm`；不用原生 `<button>` 承担主操作；`PModal` 用 `title` prop，不手写 header |
| **R10 色值** | 所有 `#xxx` 颜色必须源自设计令牌列表，禁止自创 hex |

## 六、跨模块通用问题

以下问题在多个模块中反复出现，统一记录便于批量修复：

### 1. `<RouterLink class="a-btn a-btn--primary">立即登录</RouterLink>` 模式
出现位置：`FeedReadingListView`、`FeedStarredView`、`VideoFavoritesView`、`VideoSubscriptionsView`、`ForumMyView`、`DebateMyView`、`TimelineMyView`  
→ 统一替换为 `<PButton to="/login">立即登录</PButton>`

### 2. 骨架屏分割线 `rgba(0,0,0,x)` 模式
出现位置：`ForumHomeView`、`DebateHomeView`、`FeedRecommendedView`（L148, L157）  
→ 统一替换为 `border: 1px solid var(--a-color-border-soft)`

### 3. 标题字重 `600`、`650`、`700`、`800`、`900`
遍布几乎所有模块。核心问题是 CSS 自定义属性 `--a-font-weight-black` 值为 `600`，而标题应用了 `var(--a-font-weight-black)` 但期望值应为 `500`。  
→ 需将标题的 `font-weight` 统一改为 `500` 或 `var(--a-font-weight-normal)`（值 `400`）；仅在强调态下使用 `600`

### 4. PModal 内手写 header + close button
出现位置：`TimelineEventDetailModal`、`PersonMapView`（×2）、`TimelineHomeView`（×3）  
→ 所有 `PModal` 统一传递 `title` prop，操作放入 `#footer` slot 以 `PButton` 实现

### 5. 原生 `<button>` 用于 Tab / 筛选 Chip
出现位置：`FeedStarredView`、`VideoHomeView`、`VideoImportsView`、`SettingCommunityView`、`SettingFeedSourcePanel`、`SettingMusicReviewPanel`  
→ 统一替换为 `PSegmentedControl`（互斥切换）或 `PTab`（内容切换）

### 6. `var(--a-color-accent)` / `var(--a-color-accent-success)` 未定义令牌
出现位置：`HistoryView`、`ImportsView`、`AccountSecurityPanel`、`NotificationSettingsPanel`  
→ 确认对应语义后替换为 `var(--a-color-primary)` / `var(--a-color-success)` / `var(--a-color-danger)`

### 7. 日期输入控件
出现位置：`TimelineEventFormSection`、`TimelineHomeView`、`PersonListView`  
→ 替换 `PInput` 为 `PMaskedDateInput` 以满足设计规范的 YYYY/MM/DD 顺序输入约束

### 8. 英文 kicker 暴露给用户
出现位置：`SettingManagementOverview`（"MODULES"）、`SettingRolesPanel`（"ROLE MANAGEMENT"）、`SettingAccessView`（"SITE ACCESS" 等）、`MyHubView`（"MY ATOMAN"）、`UserSettingsView`（"DANGER ZONE" 等）、`ModuleUnavailableView`（"CLOSED"）  
→ 统一改为中文描述或去除 kicker
